📚 Core Algorithm Concepts Explained

Understand the theoretical foundation behind the visualizers:

🎯 A* Search (Heuristic)

Combines Dijkstra's cost-so-far g(n) with estimated heuristic distance h(n). Yields fast shortest paths directed towards the target.

⚡ Dijkstra's Algorithm

The gold standard for weighted graphs. Explores outward in waves of increasing path cost, ensuring mathematically optimal shortest routes.

🌊 Breadth-First Search

Explores radially layer-by-layer using a FIFO queue. Guarantees the shortest number of steps on unweighted graphs.

🧩 Backtracking (CSP)

Systematic recursive trial-and-error. Explores one candidate digit at a time and rolls back immediately upon detecting constraint violations.

🧠 How Backtracking Solves Sudoku

Algorithm Deep Dive

1. Depth-First Decision Tree

The solver treats the puzzle as a tree of decisions. At each empty cell, it branches into up to 9 possible paths (one for each digit 1 through 9).

2. Constraint Satisfaction & Pruning

Before placing a number, it checks three constraints: no duplicates in the Row, in the Column, or in the 3×3 Subgrid. Illegal digits are pruned immediately without exploring downstream dead ends.

3. The Backtracking Step

If all digits 1–9 lead to conflicts at a later stage, the function resets the current cell to blank (0) and returns false to the parent call, forcing it to try the next alternate candidate.

💡 Pathfinding Lab Glossary & Concepts

What is Pathfinding?
Pathfinding is the algorithmic process of discovering a valid, walkable route from a starting point to a destination without passing through obstacles or barriers.
What is a Node?
A node is a single position or square on the grid. In graph theory, nodes (vertices) are connected by edges representing valid moves (Up, Down, Left, Right).
What is a Wall?
A wall is an impassable obstacle. Algorithms detect walls and cannot expand into or cross over them.
What is a Visited Cell?
A visited cell is a node that the algorithm has evaluated and added to its search history to avoid processing the same position multiple times in cycles.
What is the Final Path?
The connected sequence of steps from the Start Node to the Target Node reconstructed by tracing backward from the target using parent pointers.
Key Differences: BFS vs DFS vs Dijkstra vs A*
  • BFS (Breadth-First): Explores equally in concentric ripples. Guarantees shortest path on unweighted grids.
  • DFS (Depth-First): Dives as deep as possible before backtracking. Fast for exploration, but does not guarantee shortest path.
  • Dijkstra: Always expands the lowest accumulated cost first. Shortest path guaranteed for any non-negative weights.
  • A* (A-Star): Combines Dijkstra's accumulated distance with a distance estimate (heuristic) towards the target. Explores far fewer cells while still guaranteeing the shortest path!
